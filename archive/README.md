# archive/

Superseded documents, kept because they record what was intended before a
build rather than what shipped — useful when reading a decision back, useless
and actively confusing at the repository root, where two files with nearly the
same name read as two competing sources of truth.

| File | What it is |
| --- | --- |
| `MCP-PLAN-original-preimplementation.md` | The MCP plan as written **before** implementation. Superseded by `MCP-PLAN.md`, whose §0 records where this one turned out to be wrong. `AUDIT-REPORT.md` §1 flagged the pair as a divergence hazard. |
