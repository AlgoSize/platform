CI

Audit every pull request

Three steps: a key, a secret, a workflow file. Findings land in the PR as a sticky comment, in the Security tab as SARIF, and here in the runs feed.

  1. 1

    Create an API key

    A key authenticates your pipeline as this organisation — no browser session, no cookie. Owners and admins mint them on the Team screen; the full key is shown exactly once.

  2. 2

    Add it as a repository secret

    Name it ALGOSIZE_API_KEY — the workflow reads exactly that name, and skips itself with a notice (never a red build) until the secret exists.

    gh secret set ALGOSIZE_API_KEY --body '<paste the key>'
  3. 3

    Commit the workflow file

    Save as .github/workflows/algosize-audit.yml. It runs on every PR, on pushes to main, and weekly — new advisories are published against code that hasn't changed.
